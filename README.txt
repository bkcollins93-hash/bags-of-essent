BAGS OF ESSENT — MUBS BUC3106 STUDENT WEBSITE
================================================

Files included:
- index.html       Home page
- products.html    Product catalogue
- about.html       About the brand
- pay.html         How to Pay and Order
- policies.html    Policies and trust information
- style.css        Shared responsive design
- script.js        Small mobile navigation menu
- images/          Add your approved business/product images here

IMPORTANT BEFORE SUBMISSION
1. Replace all SAMPLE prices in products.html with the real prices supplied by the business.
2. Replace product photo placeholders with actual product photos. Save them as:
   images/product1.jpg, images/product2.jpg, ... images/product6.jpg
   To show the promotional poster on the Home page, copy the supplied poster image into
   this folder and name it images/brand-poster.jpg.
3. Verify the WhatsApp number in the footer and get the owner's permission to display it publicly.
4. Confirm delivery details, materials and every product claim with the business owner.
5. Payment numbers are fake examples and payments are inactive. Keep the sample warning visible.
6. The site must say "Student project for BUC3106 at MUBS."
7. Do not add customer information, passwords or private account details to the public website.

TEST LOCALLY
- Keep all HTML, CSS and JS files in the same main folder.
- Keep images inside the images folder.
- Double-click index.html to open it in a browser.
- Test every navigation link and inspect the site on phone and computer widths.

PUBLISH WITH GITHUB PAGES
1. Sign in to GitHub with the group's agreed email and create a PUBLIC repository.
2. Upload the contents of this folder to the repository root (not the enclosing folder).
3. Open Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch, branch main, folder /(root), then Save.
5. Wait for deployment and open the provided https:// address.
6. Test every page and take screenshots on a phone and computer.

This project website is a starter template. Replace the placeholder content and sample prices before final submission.
